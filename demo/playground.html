Live browser demo

This page runs the repository's unmodified ES module src/rope-kernel.js in your browser on synthetic random data, then checks the result against the repository's independent scalar reference (support/reference.mjs). Nothing is uploaded: the page makes no network requests beyond loading its own files, and has no analytics or trackers.

Configuration

Changes apply automatically. Positions startPos through startPos + seqLen − 1 must stay at or below 131071, the highest position the repository's numerical tests cover.

Scope

This is a CPU JavaScript kernel demo, not an inference engine. Browser runtimes are not part of the repository's Node CI matrix; this page's own check is what tells you whether the kernel matched the reference in your browser. Timing here is a rough, single-browser number: browser timers are deliberately coarse, the page runs on the main thread, and results vary between devices, browsers and runs.

lyle-rope-kernel-js

Experimental CPU JavaScript RoPE library. Static project information page; no kernel runs here.

Implemented scope

This package mutates Float32Array tensors in place, supports startPos for continuation, and now includes a reusable precomputed plan API.

Use npm run verify for correctness and package checks, and npm run evidence for source-identified local measurements.

Limitations

This is not an inference engine or KV cache. The WebGPU entry point executes the ordinary CPU JavaScript path; GPU computation is not implemented. Browser execution is not covered by the Node CI matrix.

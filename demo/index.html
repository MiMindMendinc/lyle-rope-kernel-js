lyle-rope-kernel-js

Experimental CPU JavaScript RoPE library. This page is static project information; the kernel runs on the live demo page.

Source and README on GitHub · v1.1.0-rc.1 (prerelease, not on npm)

Live browser demo

Open the live demo

Pick head dim, sequence length, layout and heads, rotate synthetic random data with the real ES module in your browser, check it against the scalar reference, and time it locally. No network requests beyond the page's own files, no analytics.

Implemented scope

This package mutates Float32Array tensors in place, supports startPos for continuation, and includes a reusable precomputed plan API.

Use npm run verify for correctness and package checks, and npm run evidence for source-identified local measurements.

Limitations

This is not an inference engine or KV cache. The WebGPU entry point executes the ordinary CPU JavaScript path; GPU computation is not implemented. Browser execution is not covered by the Node CI matrix; the live demo reports its own reference check in the browser you use.
